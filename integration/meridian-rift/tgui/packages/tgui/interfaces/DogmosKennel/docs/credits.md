# Dogmos Credits

Dogmos is developed for Meridian Rift, a Space Station 13 downstream of
[tgstation](https://github.com/tgstation/tgstation) and
[Nova Sector](https://github.com/NovaSector/NovaSector).

Its atmospheric simulation lineage begins with [Auxmos](https://github.com/Putnam3145/auxmos) by
Putnam3145. Dogmos' service architecture, Meridian integration, gameplay callbacks, telemetry,
verification, and Kennel interface are maintained in the Meridian Rift and Aphelion repositories by
their contributors.

The native implementation builds on the Rust and BYOND open-source ecosystems. Meridian-MCP, used
for Dream Maker analysis during development, is adapted from
[dm-mcp](https://github.com/imcynic/dm-mcp) by imcynic.

This page records project and tool lineage. Repository history remains the source for individual
contributions and authorship.
